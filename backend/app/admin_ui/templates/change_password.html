How It Works

This feature automatically updates your password:

  1. Generates a new bcrypt hash for your password
  2. Automatically updates the ADMIN_PASSWORD_HASH in your .env file
  3. Updates the password in memory for immediate use
  4. You just need to restart the backend server to fully apply changes

Note: If automatic update fails (file permissions, Docker environment, etc.), you'll see the hash to copy manually.
